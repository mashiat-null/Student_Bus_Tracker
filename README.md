# Bus Tracker Website

## Overview

The Bus Tracker Website is a full-stack web application developed as an individual learning project. The project was created to explore transport information systems, web development concepts, backend integration, and database connectivity.

## Features

- Display transport and bus-related information
- Route and schedule management
- User-friendly web interface
- Backend API development using Express.js
- MySQL database integration
- Responsive design for improved user experience

## Technologies Used

### Frontend

- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MySQL

## Purpose

This project was developed to strengthen skills in:

- Full-stack web development
- RESTful API development
- Database design and management
- Backend and frontend integration
- Building transport-related web applications

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/bus-tracker-website.git
   
2. Navigate to the project directory:
    ```bash
   cd bus-tracker-website

3. Install dependencies:
    ```bash
   npm install

4. Configure the MySQL database.

5. Start the server:
   ```bash
   npm start
